  1. 웹앱 공개 범위. 지금은 "로그인 없이 누구나, 소유자 권한으로 실행"입니다. 추천: 시세 조회용 GAS와 내 데이터용 GAS를 두 개로 나누기. 시세용은 지금처럼 공개하고, 데이터용은 "나만(MYSELF)"으로 바꿉니다(약 20분, 돈 안 듦, 이전 배포로 되돌릴 수 있음). 대안: 하나로 두고 서버에서 접속한 사람 이메일이 소유자인지 확인하기. 다만 소유자 본인이 열 때 이메일이 실제로 보이는지는 GAS에서 직접 시험해 봐야 합니다.

  4. 매매 일지가 9KB를 넘을 때 보관 방법. 지금은 넘으면 저장을 막고 경고만 띄웁니다(데이터는 이 기기에 남음). 오래 쓰려면 여러 칸으로 나눠 저장하거나 스프레드시트에 저장하도록 바꿔야 합니다.

확인 못 한 것

  • 실제 GAS에 배포해 보지 않았습니다. 고친 코드가 실제 구글 서버에서 그대로 도는지는 주인이 배포한 뒤 확인해야 합니다.
  • 실제 브라우저에서 화면을 열어 보지 않았습니다. 화면 그리기는 가짜 환경에서만 시험했습니다.
  • 네이버 시세 API가 영문 섞인 종목코드(0091C0 등)에 실제로 답하는지는 확인하지 못했습니다.
  • PropertiesService 9KB 한도는 공식 한도를 기준으로 9,000바이트에서 막도록 했고, 실제 한도에 걸리는 순간은 재현하지 못했습니다.
  • 상단 요약 카드(총 평가액 등)는 시세가 없을 때 여전히 평단가로 계산합니다. 카드별 표시만 고쳤습니다.
  • CDN 파일의 무결성 해시(SRI)는 넣지 않았습니다. Tailwind CDN(cdn.tailwindcss.com)도 버전이 고정되어 있지 않습니다.
  • 서로 다른 기기의 시계가 크게 어긋나면 "더 새로운 쪽" 판단이 틀릴 수 있습니다.
